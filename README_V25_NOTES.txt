V25 VEHICLE COVERAGE NOTES

Coverage policy implemented:
1. Traditional jeepneys: Cebu City only. A traditional jeepney route with explicit stops outside Cebu City is excluded from public journey matching and the public route-code directory.
2. South Cebu multicabs: Carcar to Talisay only.
3. North Cebu multicabs: Mandaue to Danao only.
4. Modern jeepneys and buses continue to use their documented route records and are not restricted by these multicab/jeepney limits.

Multicab routes must be entered with mode = multicab and must explicitly identify the appropriate corridor endpoints. The app does not automatically reclassify uncertain route records.

Run checks with: npm run test:routes
Run the website with: npm install, then npm run dev
