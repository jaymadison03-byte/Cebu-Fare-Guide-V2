V24 ROUTE FINDER NOTES

Run:
  npm install
  npm run test:routes
  npm run dev

The route smoke tests check 15 example direct journeys from the route directory.
Automatic route matching is local and begins after both locations are selected.
Transfer suggestions are shown only when the first and second route share a stop explicitly listed in both route sequences.

Do not treat a corridor-only match as a confirmed direct ride. In particular, the South Bus Terminal vicinity note on 10H does not establish that Route 10H boards at the terminal, and the 45/45B San Fernando–Basak listing does not establish a direct terminal-to-San Fernando trip.
